# java-lotto-precourse

## **우테코 프리코스 3주차 과제 : 로또**

### 프로젝트 설명

---

로또 발매기를 구현하였습니다.

사용자로부터 로또 구입 금액, 당첨 번호와 보너스 번호를 입력받습니다.

로또 구입 금액에 맞게 로또를 발행하여 당첨 내역을 출력합니다.

### 기능 목록

---

- [x]  사용자로부터 로또 구입 금액을 입력받는다.
- [ ]  로또 구입 금액을 1,000원으로 나누어 발행한 로또 수량을 출력한다.
- [ ]  로또 번호를 출력한다.
    - [ ]  중복되지 않는 숫자 6개를 뽑아서 오름차순으로 정렬한 로또 1개를 발행한다.
    - [ ]  발행한 로또를 출력한다.
    - [ ]  사용자가 구입한 수량만큼 로또를 발행하여 출력한다.
- [ ]  사용자로부터 당첨 번호를 입력받는다.
- [ ]  사용자로부터 보너스 번호를 입력받는다.
- [ ]  당첨 통계를 출력한다.
    - [ ]  당첨 기준과 금액별로 당첨 내역을 출력한다.
    - [ ]  소수점 둘째 자리에서 반올림한 총 수익률을 출력한다.

### 예외 처리

---

- 사용자가 잘못된 값을 입력할 경우, 예외 처리한 후 값을 다시 입력받는다.

**로또 구입 금액**

- [ ]  값을 입력받지 않을 경우
    - `[ERROR] 1,000원 단위로 로또 구입 금액을 입력해야 합니다.`
- [ ]  숫자가 아닌 문자가 포함된 경우
    - `[ERROR] 로또 구입 금액은 문자가 아닌 숫자여야 합니다.`
- [ ]  공백이 있는 경우
    - `[ERROR] 로또 구입 금액에 공백이 없어야 합니다.`
- [ ]  1,000원으로 나누어 떨어지지 않는 경우
    - `[ERROR] 로또 구입 금액은 1,000원 단위여야 합니다.`

**로또 당첨 번호**

- [ ]  값을 입력받지 않을 경우
    - `[ERROR] 1부터 45 사이의 로또 번호 6개를 입력해야 합니다.`
- [ ]  6개가 아닐 경우
    - `[ERROR] 6개의 로또 번호를 입력해야 합니다.`
- [ ]  1~45 사이의 숫자가 아닌 경우
    - `[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.`
- [ ]  숫자가 아닌 문자가 포함되어 있는 경우
    - `[ERROR] 로또 번호는 문자가 아닌 1부터 45 사이의 숫자여야 합니다.`
- [ ]  콤마가 아닌 다른 구분자로 구분할 경우
    - `[ERROR] 콤마(,)로 구분한 로또 번호를 입력해야 합니다.`

**보너스 번호**

- [ ]  값이 1개가 아닌 경우 (값을 입력받지 않을 경우)
    - `[ERROR] 보너스 번호 1개를 입력해야 합니다.`
- [ ]  1~45 사이의 숫자가 아닌 경우
    - `[ERROR] 보너스 번호는 1부터 45 사이의 숫자여야 합니다.`
- [ ]  숫자가 아닌 문자가 포함되어 있는 경우
    - `[ERROR] 보너스 번호는 문자가 아닌 1부터 45 사이의 숫자여야 합니다.`
