# java-lotto-precourse

# **우테코 프리코스 3주차 과제 : 로또**

## 프로젝트 설명

---

로또 발매기를 구현하였습니다.

사용자로부터 로또 구입 금액, 당첨 번호와 보너스 번호를 입력받습니다.

로또 구입 금액에 맞게 로또를 발행하여 당첨 내역을 출력합니다.

## 기능 목록

---

### 입력

- [x]  로또 구입 금액을 입력받는다.
- [x]  당첨 번호를 쉼표(,)를 기준으로 입력받는다.
- [x]  보너스 번호를 입력 받는다.

### 유효성 검사 (예외 발생 시 [ERROR] 메시지 출력 후 재입력)

- 공통 유효성 검사
    - InputValidator
        - [ ]  빈 값을 입력한 경우
            - [ERROR] 입력이 비어있습니다.
        - [ ]  숫자가 아닌 문자가 포함된 경우
            - [ERROR] 숫자가 아닌 문자가 포함되어 있습니다.
- 로또 구입 금액 유효성 검사
    - InputValidator
        - [ ]  금액이 양수가 아닌 경우
            - [ERROR] 양수만 입력할 수 있습니다.
    - LottoValidator
        - [ ]  구입 금액이 1,000원 단위가 아닌 경우
            - [Error] 금액은 1,000원 단위여야 합니다.
- 당첨 번호 유효성 검사
    - InputValidator
        - [ ]  1~45 사이의 숫자가 아닌 경우
            - [ERROR] 숫자는 1~45 사이의 숫자여야 합니다.
        - [ ]  당첨 번호의 개수가 6개를 초과할 경우
            - [Error] 로또 번호의 개수는 6개를 초과할 수 없습니다.
        - [ ]  당첨 번호에 중복이 있는 경우
            - [ERROR] 당첨 번호는 중복될 수 없습니다.
- 보너스 번호 유효성 검사
    - InputValidator
        - [ ]  1~45 사이의 숫자가 아닌 경우
            - [ERROR] 숫자는 1~45 사이의 숫자여야 합니다.
        - [ ]  보너스 번호가 당첨 번호와 중복되는 경우
            - [ERROR] 당첨 번호는 보너스 번호와 중복될 수 없습니다.

### 메인 로직 실행

- [x]  사용자가 구매한 로또 수량을 계산한다.
- [x]  1~45 사이의 중복되지 않는 당첨 번호 6개를 뽑아 로또 1개를 발행한다.
- [x]  발행한 로또 번호를 오름차순으로 정렬한다.
- [ ]  로또를 수량만큼 발행한다.
- [ ]  로또를 당첨 번호, 보너스 번호와 비교하여 당첨 내역을 계산한다.
- [ ]  총 수익률을 계산하여 소수점 둘째 자리에서 반올림한다.

### 출력

- [ ]  사용자가 구매한 로또의 수량을 출력한다.
- [ ]  로또를 수량만큼 출력한다.
- [ ]  당첨 통계(내역)를 출력한다.
- [ ]  총 수익률을 출력한다.
